# Master Video Drop

Place a newly finished master video in this folder, then tell Codex that it is ready.

That is the entire required handoff. You do not need to rename the file or create a notes document.

The original master will be treated as read-only. Codex can inspect it and, with your direction, create separate upload copies, excerpts, vertical clips, thumbnails, and other promotional assets.

Media placed here is intentionally excluded from Git because it may be large and unpublished. This README remains tracked so the folder is always available.
