# Platform Strategy

Use these durable principles for Verse Studio short-form publishing. Refresh changing claims against official platform guidance before relying on them.

Last platform-guidance review: 2026-07-15

## Studio Pattern

- Treat the website as the home for flagship videos and longer work.
- Use social channels for complete short clips, excerpts, ambient experiments, process glimpses, and occasional outtakes.
- Build recognition through a consistent creative identity rather than trend-chasing.
- Track results by clip, platform, framing, text choice, and posting time so later decisions use Verse Studio's own evidence.

## Creative Decisions

- Make the visual idea legible in the opening seconds.
- Preserve the whole clip unless Alex requests otherwise.
- Keep original audio when it contributes atmosphere; mute distracting or irrelevant audio.
- Prefer a blurred full-height background behind a centered horizontal frame when a destructive vertical crop would remove important content.
- Avoid generic hooks, hashtag stuffing, engagement bait, and captions that over-explain the work.
- Add no public text without Alex's approval.

## Discovery Metadata

- Treat hashtags as classification and search context, not a substitute for a strong opening, completion, rewatches, shares, saves, or follows.
- Use only tags that literally describe the clip, audience, medium, setting, or mood. Never add unrelated trending tags, `#fyp`, keyword clouds, or repeated generic blocks.
- Put the Verse voice first. When tags are useful, separate them from the destination line with a blank line so they do not interrupt the caption's speaker.
- Research current audience language with native tools when practical: TikTok Creator Search Insights and Creative Center, YouTube search suggestions, Instagram search, and X search. Record the date when a trend-sensitive choice affects publication.
- Use one stable niche tag plus one or two scene-specific tags when evidence is limited. Vary the scene-specific tags across excerpts so Verse can learn which audience cluster responds.

## Platform Fit

Verify the visible signed-in account before every upload. Expected Verse handles are TikTok `@verse_vids`, X `@verse_vids`, YouTube `@verse-vids`, and Instagram `@verse.videos`; stop if the active account differs.

### TikTok

- Prefer 1080x1920 H.264 MP4 with useful audio retained.
- Use the signed-in Verse account and verify the handle before publishing.
- Use about three highly relevant hashtags after the voiced caption and destination line. TikTok identifies hashtags and sound as content-information signals, but says user interactions such as time spent watching are generally weighted more heavily in For You recommendations.
- Match caption language and tags to real search intent. Use Creator Search Insights for current topics or content gaps when available; do not chase an unrelated trend.
- Expect web uploads to be brittle; preserve any prepared draft and report the exact blocker.
- Sources verified 2026-07-15: <https://support.tiktok.com/en/using-tiktok/exploring-videos/how-tiktok-recommends-content> and <https://support.tiktok.com/en/using-tiktok/growing-your-audience/creator-search-insights>.

### Instagram Reels

- Prefer vertical presentation and a clear cover frame.
- Avoid exports that look watermarked or recycled from another platform.
- Keep hashtags in the caption, below the voiced line and destination line. Use zero to three precise tags by default and never exceed the visible product limit; a large hidden block or first-comment dump is not a growth strategy.
- Hashtags make a public post eligible for the corresponding hashtag page, but they should be treated as classification rather than the primary source of reach. Optimize the clip for watching, sharing, saving, and profile visits first.
- Source verified 2026-07-15: <https://www.facebook.com/help/instagram/351460621611097/>.

### YouTube Shorts

- Publish social clips as Shorts rather than flagship uploads.
- Use vertical or square framing and verify the public Shorts URL.
- Titles, descriptions, and hashtags require Alex's approval.
- Put descriptive search language in the title. Keep the description in the Verse voice, followed by a minimal destination line and up to three directly relevant hashtags.
- Do not rely on the raw full-video URL in a Shorts description for conversion because YouTube makes Shorts-description URLs non-clickable. When advanced features are available, attach the full film as the Short's related video; viewers then receive a clickable link below the channel handle.
- Treat title, thumbnail, description, appeal, engagement, and satisfaction as higher priorities than tags. Use tags mainly for misspellings and hashtags only for genuine topic pages.
- Sources verified 2026-07-15: <https://support.google.com/youtube/answer/13748639>, <https://support.google.com/youtube/answer/14075157>, <https://support.google.com/youtube/answer/6390658>, and <https://support.google.com/youtube/answer/16559650>.

### X/Twitter

- Prefer the original horizontal framing when it best presents the scene.
- No-text video posts are valid when Alex requests them.
- Use concise conversational copy only after approval.
- Default to no hashtags in an ordinary organic Verse post; X's current organic guidance explicitly recommends avoiding them. If a tag serves a specific, genuinely relevant search or live conversation, use one and never more than two.
- Never attach an unrelated trending tag to gain attention. X may restrict reach for excessive or manipulative hashtag use.
- Sources verified 2026-07-15: <https://business.x.com/en/basics/organic-best-practices>, <https://help.x.com/en/using-x/how-to-use-hashtags>, and <https://help.x.com/en/rules-and-policies/authenticity>.

## Growth Review

When performance data is available, compare completion rate, rewatches, shares, saves, profile visits, follows, and substantive comments. Do not judge a format from views alone or make broad conclusions from one post.
